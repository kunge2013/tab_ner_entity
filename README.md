# 数据库字段属性实体识别模型

基于BERT的命名实体识别模型，用于从自然语言查询中提取数据库字段相关的实体。

## 功能说明

1. **字段名识别 (FIELD)**：识别数据库字段名，如"商品"、"价格"、"订单"等
2. **时间抽取 (TIME)**：识别时间表达，如"昨天"、"2023-01-01"、"本月"、"2023年第三季度"等
3. **指标获取 (METRIC)**：识别指标类实体，如"购买数量"、"销售额"、"订单量"等
4. **维度获取 (DIMENSION)**：识别维度类实体，如"张山"、"北京"、"中国移动"等

## 标签体系

- `O`: 非实体
- `B-FIELD`: 字段名开始
- `I-FIELD`: 字段名内部
- `B-TIME`: 时间开始
- `I-TIME`: 时间内部
- `B-METRIC`: 指标开始
- `I-METRIC`: 指标内部
- `B-DIMENSION`: 维度开始
- `I-DIMENSION`: 维度内部

## 使用方法

### 1. 训练模型

```bash
python train.py
```

训练过程会：
- 加载训练集、验证集、测试集
- 训练10个epoch（可在config.py中调整）
- 在每个epoch后在验证集上评估
- 保存最佳模型（根据F1分数）和最终模型

### 2. 测试模型

```bash
python test.py
```

测试脚本会：
- 加载最佳模型
- 在测试集上进行评估
- 显示总体指标和各实体类型的指标
- 生成详细分类报告
- 可视化部分预测结果

### 3. 推理使用

#### 交互式推理

```bash
python inference.py
```

运行后会进入交互模式，可以输入自然语言查询进行实体识别。

示例查询：
```
昨天张山购买了多少商品
本月北京的销售额是多少
2023年第三季度上海地区用户增长率
```

#### 批量推理

```bash
python inference.py input.txt output.json
```

- `input.txt`: 包含查询的文本文件，每行一个查询
- `output.json`: 输出的JSON格式结果

## 数据格式

训练数据采用BIO标注格式：

```
昨    B-TIME
天    I-TIME
张    B-DIMENSION
山    I-DIMENSION
购    O
买    O
了    O
多    O
少    O
商    B-FIELD
品    I-FIELD

(空行表示句子分隔)
```

## 数据集说明

当前数据集包含：
- **训练集**: 30条标注数据
- **验证集**: 15条标注数据
- **测试集**: 15条标注数据

数据覆盖了多种场景：
- 时间表达（昨天、今天、本月、上周五等）
- 维度表达（张山、北京、中国移动、上海地区等）
- 指标表达（购买数量、销售额、用户增长率等）
- 字段表达（商品、订单、产品、用户等）

## 配置参数

主要配置参数在 `config.py` 中：

```python
# 模型配置
MODEL_NAME = "bert-base-chinese"  # 使用中文BERT
MAX_LENGTH = 128
BATCH_SIZE = 16
LEARNING_RATE = 2e-5
NUM_EPOCHS = 10

# 标签体系
LABELS = ['O', 'B-FIELD', 'I-FIELD', 'B-TIME', 'I-TIME', 
          'B-METRIC', 'I-METRIC', 'B-DIMENSION', 'I-DIMENSION']
```

## 评估指标

使用seqeval库计算以下指标：
- **Accuracy**: 准确率
- **Precision**: 精确率
- **Recall**: 召回率
- **F1 Score**: F1分数

## 常见问题

**Q: 训练时内存不足怎么办？**
A: 减小BATCH_SIZE配置，或使用梯度累积

**Q: 如何使用自定义数据集？**
A: 按照BIO格式准备数据，修改config.py中的数据路径

**Q: 预测结果不准确怎么办？**
A: 增加训练数据量，调整学习率和训练轮数，或使用更强的预训练模型
